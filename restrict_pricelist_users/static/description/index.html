Show each salesperson only the pricelists they are allowed to use

Wholesale, distributor or VIP prices should only be visible to the people who work with those customers. Add Allowed Users on a pricelist and Odoo hides it from everybody else — in the pricelist menu, on quotations, on customers and everywhere a pricelist can be selected.

Key features

Allowed Users per pricelist
Pick the users who may use a pricelist. Leave it empty and the pricelist stays public. 		Two access levels
Own Pricelists for salespeople, All Pricelists for managers who must see everything.
Safe to install
Users without either group keep the standard Odoo behaviour. Nothing is hidden until you assign the groups. 		Native Odoo security
Built on standard access rules, no overrides of core methods. Group changes apply immediately.

Configuration

1. Enable pricelists

Sales → Configuration → Settings → Pricing → Pricelists (standard Odoo setting).

2. Give users an access level

Activate the developer mode, open Settings → Users & Companies → Groups and add the users on the Users tab of Sales / Own Pricelists (restricted salespeople) or Sales / All Pricelists (managers). Users in neither group keep the standard behaviour.

3. Choose who can use each pricelist

Sales → Products → Pricelists, open a pricelist and fill Allowed Users. Leave it empty to make the pricelist visible to everybody.

Good to know

  • Only read access is restricted. Creating, editing and deleting pricelists still follows the standard Odoo groups (e.g. Products: Administrator).
  • A pricelist with an empty Allowed Users field is visible to everybody.
